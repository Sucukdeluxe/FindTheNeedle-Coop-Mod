These six 1920x1080 images were captured in the native Find The Needle Demo V62 game engine with Multiplayer Enhanced .62.

The game rendered through D3D12 on a separate inactive Windows desktop, using an isolated profile and a staged demonstration scene. No live player save was used or edited. The models, textures and lighting come from the installed game and mod; the English headings were rendered as an overlay in the same engine.

These are staged feature demonstrations, not AI-generated models, a performance benchmark or evidence of a two-PC multiplayer test. The overhead image uses the mod's overhead camera transform and projection.
